# Desarrollo de Plataforma Web con Motor de Validación - Ferretería Tornicomple

Plataforma web con motor de validación automática para el aseguramiento de la calidad estructural de datos financieros (ventas y costos) en la microempresa **Ferretería Tornicomple** de Santiago de Cali.

## 🛠️ Stack Tecnológico
* **Backend:** Python 3.12+, FastAPI, Pydantic V2, Pandas.
* **Frontend:** React 19, TypeScript, Vite, Tailwind CSS, shadcn/ui.
* **Base de Datos:** PostgreSQL, SQLAlchemy.
* **Metodología:** Extreme Programming (XP) bajo la norma ISO/IEC 25012.
